# Prince Gajjar — Senior Full-Stack & Systems Engineer

> **Awwwards-tier Portfolio & Interactive 3D WebGL Drift Lab** built with Next.js 16 (App Router), React 18, Three.js, Tailwind CSS, TypeScript, and Web Audio API.

---

## 🏎️ Features & Architecture

- **Interactive 3D WebGL Freeroam Drift Game ("Apex Drift 3D")**:
  - Realistic dual-axle vehicle dynamics (Pacejka model) with genuine tire slip mechanics and counter-steering stabilization.
  - Suspension body roll (centrifugal roll) & pitch (acceleration squat & braking dive).
  - 4-speed automatic transmission with realistic RPM curve and redline rev-limiter bounce (`stut-tut-tut`).
  - Persistent 3D rubber skid mark ribbons baked onto procedural asphalt tarmac.
  - Volumetric 3D tire smoke particles and dynamic chase camera with drift sway.
  - Real-time procedural audio synthesis with engine revs and tire screeches (Web Audio API).
- **Aesthetic Modern UI & Micro-Animations**:
  - 3D Topological Canvas Waveform hero mesh.
  - Ambient fluid aura backdrops with mouse tracking.
  - Cryptographic glyph text scramble on interactive headers and metrics.
  - Apple Pro crystalline glassmorphic cards with dynamic radial spotlights.
  - Minimalist custom cursor with Lerp ring follower.
- **Enterprise Performance & SEO**:
  - Next.js 16 App Router with static generation.
  - Dynamic `sitemap.xml`, `robots.txt`, and PWA `manifest.webmanifest`.
  - Schema.org structured data for SEO rich snippets.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.17+ or 20+
- npm / yarn / pnpm

### Installation

```bash
git clone https://github.com/DevFlowTech/Portfolio-Website.git
cd Portfolio-Website
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
